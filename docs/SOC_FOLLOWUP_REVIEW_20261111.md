# SOC 추가 검수 기록 — 2026-11-11

## 확인한 문제와 수정

기존 검수 배포 `4ef43f9`의 실제 화면에서 확인했습니다.

1. 시험 계정 로그아웃 뒤에도 홈에 시험 대회가 남았습니다. 로그아웃 상태에서 새로고침한 후 다시 시험 로그인하면 반대로 빈 대회 목록이 유지됐습니다. 홈·참가신청 화면이 계정 변경 시 대회와 참가 부문을 다시 조회하도록 수정했습니다. 이전 조회 응답이 뒤늦게 도착해 현재 화면을 덮어쓰지 않도록 했습니다.
2. 공개된 접수 대회가 있어도 홈 상단에 ‘첫 시즌 준비 중’이 고정 표시됐습니다. 실제 공개 일정과 접수 기간을 읽어 ‘대회 접수 중’, ‘대회 일정 안내’, ‘다음 대회 준비 중’을 표시합니다. 관리자 패널에서 사이트로 돌아올 때도 다시 조회합니다.
3. 대회 상태가 접수 개시로 저장돼 있으면 기간 전·후에도 접수 중으로 보일 수 있었습니다. 홈과 대회 목록의 표시를 시작·마감 시각과 일치시켰습니다. 서버의 참가 자격·기간·요금 검사는 유지합니다.
4. 홈의 ‘다음 대회’가 전체 목록의 앞 3개여서 과거 대회가 새 일정을 가릴 수 있었습니다. 한국시간 기준 지난 날짜와 종료된 대회를 제외한 다음 일정을 표시합니다. 지난 대회 원본과 기록은 삭제하지 않습니다.
5. 대회 조회 실패 시 다시 불러오기 버튼을 추가했습니다. 조회 실패를 ‘대회 없음’으로 표시하지 않습니다. 신청내역은 API에서 받은 대회명을 우선 사용합니다.
6. 공개 화면 12개의 하단 ‘첫 시즌 준비’ 고정 문구를 공고 확인 안내로 바꿨습니다.
7. 상품·훈련·프로·지원 소개에서도 로그인 전후 목록이 갱신되도록 했습니다. 실제 공고가 있어도 ‘첫 행사 기획 중’, ‘제품 준비 중’으로 단정하던 문구를 상품·공고별 확인 안내로 바꾸고, 선수지원 계획 금액과 확정 공고를 구분했습니다.
