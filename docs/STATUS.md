## 2026-11-09 실제 대회 운영 보완 — 추가 변경

- 업무 담당자·검토자·기한 변경, 승인 요청 철회, 취소. 담당 변경 시 기존 승인 무효화. P03는 제출 시 대회 설정 지문을 저장하고 검토·개시 시 다시 대조.
- 운영센터 접수 개시 점검: DB, 계좌, 접수 일정, 장소, 승인 규정, 부문, 현재 설정 독립 승인이 없으면 개시 거부. 일반 대회 편집 API로도 동일 검사를 적용.
- 같은 수납계좌의 합산입금 2~100건 배분. 합계 일치·정상 신청·기한·의존성 검증. 일부 실패 시 전체 롤백. 각 신청별 전액 배분이며 과입금 잔액이나 임의 정정 기능은 포함하지 않음.
- 취소 수수료 공제 후 부분금액 최종 환불. 승인액 이하 임의 지급이 아니라 승인된 정확한 금액만 기록. 신청별 최종 환불 1회 후 참가신청 종료. 반복 분할지급은 미지원. 본인 참가비를 본인이 확인할 수 없음.
- 보호자 관계/동의 원본 확인 기록·철회·감사. 철회 시 체크인·계체·새 대진 생성 차단. 이미 진행 중인 경기와 공개 결과 조치는 운영자의 현장 중지·정정 절차가 필요.
