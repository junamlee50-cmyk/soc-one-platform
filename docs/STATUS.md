1. SOC 전용 PostgreSQL 공급자 연결·무료/유료 조건 검토. 기존 데이터 정합성 검사→백업→빈 DB 이관→조회 대조→환경 전환. 운영 복구·장애·부하 리허설.
2. 배포제한 해소 후 기존 Git 프로젝트에서 검수 배포. 건강검사 SHA/실제기능/주소 대조 후 두 주소를 같은 검증 배포에 연결. 이번에는 미검증 배포를 대표주소로 승격하지 않음.

5. PG 계약·서버승인·서명웹훅·정산/환불, 실거래와 시험거래 분리. 수기확인은 실제 거래증빙 확인을 전제로 함.
6. 선수지원 예산·정원·승인·계약·지급, 훈련 협약·정원·이용한도·정산, 지역위원 평가 확정 및 수당, 상품 주문·재고·배송·사업회계.
