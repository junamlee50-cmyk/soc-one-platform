# SOC ONE 계산·운영 엔진

현재 규정은 정식 공고 전 검토 중입니다. [충돌표](RULE_CONFLICTS.md)를 우선 확인하십시오. 과거 이 문서의 숫자가 승인된 운영규정이라는 의미는 아닙니다.

- 코드 검토안: `lib/rules.js`, 미확정 인원 보정값은 null.
- 승인: CEO만 새 버전 생성 가능. 명시적 승인·사유·감사기록 필수. 저장된 버전 덮어쓰기 금지.
- 대회: 승인된 규정 ID 연결. 대진 생성 시 규정 스냅샷 보관. 대진 생성 후 대회 배수·규정 변경 차단.
- 점수: 실제 완료 경기의 승리만 계산. 부전승은 승리점수 없음. 메달 보정은 승인된 규정의 참가인원 구간을 사용.
- 시즌: 한국시간 개최연도, 부문별 최고6개 대회, 중복·취소·무효 이벤트 제외, 동점 공동순위.
- 분류: GI/NO-GI·연령·성별·벨트·체급·앱솔루트 여부 6요소. 기존 불완전 분류는 공식 공개랭킹에서 제외.
- 기록 정정, 시즌 승급 승인, 모든 부문에 출전점수를 어떻게 배분할지는 추가 구현·규정확정 필요.
- 선수지원 검토 점수와 경기 랭킹은 별개. 점수 저장은 후원선정·계약·지급을 의미하지 않음.

테스트는 제도 승인을 대신하지 않습니다. 상세 시험·배포 상태는 [STATUS.md](STATUS.md)에 기록합니다.
