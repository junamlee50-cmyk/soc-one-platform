# SOC 실운영 준비 — 2026-11-10

현재 변경은 검수용이다. 운영 DB 이관, 이메일 발송, 실제 계좌와 운영 주체가 확정되지 않았으므로 실운영 가능 판정이 아니다. PG는 현재 운영 필수조건에서 제외한다.

## 이번 구현

- 관리자 `운영 설정`: 운영 주체·대표자·주소·고객 연락처·개인정보 담당자·약관/환불 안내의 초안 저장과 공개 버전을 분리. CEO만 공개 및 신규 가입 개시/일시중지. 변경 충돌 검사와 감사 이력.
- 공개 약관 페이지와 메인/마이페이지 가입 동의를 연결. 운영환경에서 미공개 정책·이메일 미설정 상태의 신규 회원가입 차단. 동의한 정확한 정책 ID/버전을 회원 기록에 보관하고 낡은 정책으로 가입 거절.
- 대회 신청 시 공개된 환불 안내 동의 및 원문 스냅샷 저장. 이후 정책 변경이 기존 신청의 조건을 덮어쓰지 않음.
- 로그인한 회원의 문의 접수와 본인 내역 조회, 운영진 답변·상태 관리. 타인 신청번호 첨부·일반회원 답변·오래된 수정·단시간 연속문의 차단. 답변과 감사기록을 같은 트랜잭션으로 저장.
- 관리자 메뉴에 운영 설정/문의 관리 추가. 관련 화면은 no-store 및 서비스워커 캐시 제외.

## 운영 전 필요한 실제 입력과 연결

1. SOC 운영 주체명, 대표자, 주소, 개인정보 담당자, 문의 전화·이메일.
2. 수납 은행·계좌번호·예금주와 입금기한. 확정 약관·개인정보처리방침·환불 안내.
3. 운영 Neon 프로젝트 접근 연결. 원본 보존 백업 후 빈 운영 DB 이관·SOC ID/금액/건수 대조·복구 리허설.
4. Resend 발신 주소/도메인 인증과 API 키를 Vercel 보안 환경변수로 등록. 비밀키는 채팅·문서·저장소에 기록하지 않음.
5. 대표 관리자 계정과 독립 검토/입금 담당자 설정, 추가인증 등록, 실제 인증·복구 이메일 수신 확인.
6. 같은 배포 버전에서 가입→신청→실제 은행 대조→QR/계체→경기/정정→환불/장부를 검증. 정책·계좌·대회 개시 점검을 통과한 후 정식 주소로 전환.

선수지원 정식 선발·계약·지급, 훈련 정산, 상품 주문/재고 등은 이 변경의 구현 범위에 포함하지 않는다. 기존 사전등록·차단 상태를 완성 기능으로 안내하지 않는다.
