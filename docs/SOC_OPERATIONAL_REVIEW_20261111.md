# SOC 운영 기능 검토·수정 기록

기준일: 2026-11-11. PG 연동 제외, 무통장입금 운영 기준. 이 문서는 소스·격리 자동시험의 결과이며 정식 운영 승인서가 아닙니다. 배포 후 직접 조작 결과는 [별도 검수 기록](SOC_DEPLOYED_QA_20261111.md)을 확인하세요.

## 이번 변경

- 도장 등록 반려 사유 → 본인 보완 → 재신청 → 관리자 재심사 → 내 알림 연결. 기존 도장·회원 기록 보존.
- 참가 부문 수정 기능과 변경 이력. 신청 기록이 생긴 부문의 자격 조건 변경 금지, 참가 인원보다 정원 축소 금지, 대진 생성 후 변경 금지. 부문 변경 시 대회 개시 승인을 다시 확인.
- 상품 등록·공개·주문·입금 신고·실제 입금 확인·배송·환불 검토·실제 환불 기록. 미반품 상품은 판매 재고로 되돌리지 않음.
- 합동훈련 등록·협약 확인·독립 승인·예약·입금·개최 도장 출석 확인·독립 정산 승인·실제 지급 기록.
- 선수지원·프로 초청매치 모집·지원신청·독립 심사·계약 증빙·한도 내 분할 지급. 확보 예산과 1인 한도를 서버에서 검사.
- 심판·지역위원 교육·활동·평가·수당 기록, 대상자의 증빙 제출, 독립 승인, 수당 지급 기록.
- 공지·콘텐츠 본문·유튜브 링크 수정, 공개·비공개, 버전 충돌 검사. 파트너 계약·미수금 수정과 확정 파트너 공개.
- 일반회원 가입 선택 추가. 격리된 시험 DB에서만 작동하는 일반회원·선수·관장·승인 관리자 시험 계정 추가.
- 대회 입금 증빙을 상품·훈련·지원 장부에서 중복 사용하지 못하도록 통합 검사. 장부 수정·삭제 차단. 승인과 지급 담당자 분리.
- 대회 장부와 별도로 사업 수납·지급 및 전체 입출금 차액을 경영 현황에 표시. 실제 은행 잔액이나 회계 손익으로 표시하지 않음.
- 홈페이지 문구, 소속 도장, 사전등록, 한국어 상태, 승리방법, 경기 부문, 안내 문구 정리. 날짜는 한 입력란에 연월일 또는 연월일시분을 연속 입력.

미구현 사항을 안내 문구만 바꾸어 완료로 처리하지 않았습니다. 일부 구현 항목 중 계약별 정산·평가 자동화는 임의의 사업조건을 만들지 않고, 현재 가능한 수동 증빙·승인·지급 기록까지 연결했습니다. 실제 운영에 필요한 추가 산식은 아래 결정사항을 받은 후 적용해야 합니다.

## 시험 증거

- `npm run validate`: 126개 자동시험 통과. 소스 문법·경로, 권한, 저장·조회, 동시성, 금액, 데이터 보존, 롤백 포함.
- 격리 Chromium 실제 DOM 조작: 가입→도장→대회→신청→시험 입금→체크인·계체→경기→영상·입상→정정. 별도 환불·상품·지원·훈련·심판 수당·콘텐츠·스폰서 시험.
- 브라우저 시험은 실제 은행·실제 이메일·운영 회원 자료를 사용하지 않습니다. 이메일은 격리 발송함, 유튜브 이동 자동시험은 격리 응답입니다.
- `docs/qa/ui-control-inventory.json`: 34개 페이지, PC 1365px·모바일 360px, 가로 넘침 없음. 665개 보이는 입력·버튼·링크 목록. 화면 목록화와 개별 기능 실행 시험은 구분됩니다. 숨겨진 탭과 조건별 버튼은 아래 API·소스 목록 및 통합시험과 함께 확인합니다.
- 자동시험 주요 파일: `tests/database.test.js`, `tests/demo.test.js`, `tests/browser-full-journey.mjs`, `tests/browser-business.mjs`, `tests/browser-inventory.mjs`.
- 배포된 검수 사이트 수동 시험, 실제 이메일 수신, 휴대전화 카메라·스캐너·프린터 시험은 서로 다른 검증입니다. 수동 배포 시험 결과는 별도 보고합니다.

## 대표님에게 필요한 확정 정보

1. SOC 운영 주체의 상호·대표자·사업자정보·주소·고객문의 연락처와 공개할 이용약관·개인정보처리방침·취소환불 기준.
2. 은행명·계좌번호·예금주·입금 기한과 대조 담당자. 계좌는 관리자에서 입력하고 실제 거래내역을 확인해야 합니다.
3. 인증 메일 발송 서비스 계정과 검증된 발신 주소. API 비밀키는 환경변수 보관, 공개 화면·저장소에 입력하지 않습니다.
4. 최초 운영 대회의 실제 일정·장소·참가 부문·요금·규정·책임자 및 독립 승인자.
5. 지원·프로·훈련·상품의 확정 예산·계약·기간·정원·반품/환불 조건. 화면에 남은 지원금액·인원은 계획안입니다.
6. 지역위원 평가의 확정 산식·평가기간·분모 기준, 선수 활동 매출의 배분·비용 공제·정산 기준. 이 기준 없이 자동 점수·자동 배분을 확정하지 않습니다.

## 데이터와 배포 구분

- 원래 검수 회원 DB와 `soc_demo` 시험 DB는 분리됩니다. 시험 계정은 production에서 로그인할 수 없습니다.
- 기존 회원·도장·신청·금액·장부를 일괄 삭제하거나 초기화하지 않았습니다.
- 새 마이그레이션은 사업 장부의 증빙 중복 인덱스와 수정·삭제 차단 트리거입니다. 원장 수정 기능을 만들지 않습니다.
- 검수 배포와 정식 배포를 구분하며 main 병합·운영 도메인 전환은 아직 수행하지 않습니다.
- 이 상태를 ‘전체 완성’ 또는 ‘실운영 가능’으로 보고하지 않습니다. 외부 연결·실제 자료·기기 검증과 일부 사업 산식이 남아 있습니다.
